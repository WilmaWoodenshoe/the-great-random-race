# Schermontwerpen

Gemaakt in Claude Design op basis van `voorbeeld-ontwerp.png`. Open de HTML-bestanden in een browser om ze te bekijken. Alle schermen zijn 390 × 844 pixels (telefoon).

| Bestand | Scherm | In v0.1? |
|---|---|---|
| `Welcome.html` | Eerste start, met tip om de app op het beginscherm te zetten | Ja |
| `Main.html` | Home: Gerard, positie, status, knop naar de race | Ja |
| `Race.html` | Racekaart met bordjes en Gerards positie | Ja |
| `Event.html` | Keuze-event ("Eet hem / Negeer hem / Ga erop zitten") | Ja |
| `Racer.html` | Gerards profiel met eigenschappen | Ja |
| `Leaderboard.html` | Tussenstand van de 5 racers | Ja |
| `Journal.html` | Gerards journaal (tijdlijn) | Ja |
| `Action.html` | Actie van vandaag (één per dag) | Ja |
| `Finish.html` | Uitslag met confetti | Ja |
| `KiesRacer.html` | Kies je racer (9 figuren) | Later, wel ontworpen |
| `Accessoires.html` | Collectie / accessoires | Later, wel ontworpen |
| `Huisstijl.html` | Kleuren, letters, knoppen, animaties | Referentie |

Opmerkingen:
- In v0.1 is het "Collectie"-tabblad in de menubalk nog niet bruikbaar; toon het als "binnenkort" of laat het weg.
- De bordjes op de kaart zijn leeg in de afbeelding; de app zet de namen er zelf op. De posities van de bordjes staan in `Race.html` (in pixels op 366 px breedte; de kaart is 987 × 1517 px).
- Sommige kleine plaatjes (accessoires, medailles, journaal-icoontjes, aardbei-event) zijn uit het voorbeeldontwerp geknipt en worden later vervangen door betere versies met dezelfde bestandsnaam.
- De getallen in de ontwerpen (km, posities) zijn voorbeelden.
